Technical Capabilities Implemented

✅ CRUD Operations:

Create, Read, Update, and Delete tickets with modal popups and real-time state synchronization.

✅ Login & Register:

Client-side authentication with session persistence in localStorage.

✅ Frontend Form Validation:

Email regex checking, minimum password lengths, confirmation matching, and field-level red error styling.

✅ Forgot Password:

2-step recovery simulation checking existing records and securely updating credentials.

✅ Profile Management:

View and edit personal details (Name, Bio, Phone) plus secure password change verification.

✅ User Lists & RBAC:

Admin-only user directory with role assignment and self-protection deletion guards.

✅ Responsive Application:

Mobile-friendly CSS with responsive navigation, flexbox filters, and responsive tables.

✅ Automated Test Cases:

Built-in browser test runner with 14 automated unit tests for validation, auth, and CRUD.
